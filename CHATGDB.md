# ScoutOffice : bureautique FSGGB

Suite bureautique en ligne, sans installation, servie par GitHub Pages (https://fsggb.github.io/ScoutOffice/). Les applications sont des versions web de logiciels libres (assemblées depuis `apps.yml`) ; elles fonctionnent dans le navigateur et enregistrent les fichiers sur l'ordinateur de l'utilisateur. Chaque application est listée dans ScoutHub sous son nom d'usage.

| Application (nom affiché) | Équivalent d'usage | Adresse | Sert à |
|---|---|---|---|
| Word | traitement de texte | /ScoutOffice/Word/ | lettres, comptes rendus, documents |
| Excel | tableur | /ScoutOffice/Excel/ | tableaux, budgets, listes |
| PowerPoint | présentations | /ScoutOffice/PowerPoint/ | diaporamas |
| Acrobat (PDF) | lecture et édition de PDF | /ScoutOffice/PDF/ | lire, annoter, modifier des PDF |
| Photoshop | retouche d'images | /ScoutOffice/Photoshop/ | retouche et création d'images |
| Illustrator | dessin vectoriel | /ScoutOffice/Illustrator/ | logos, schémas, affiches |
| Premiere Pro | montage vidéo | /ScoutOffice/Premiere/ | montage de films de camp |
| Excalidraw | dessin libre | /ScoutOffice/Draw/ | schémas à main levée, tableaux blancs |

## Règles communes
- Pas de compte nécessaire. Enregistrer = télécharger le fichier sur l'ordinateur ; ouvrir = choisir un fichier de l'ordinateur.
- L'ancien stockage dans GitHub n'existe plus ; ScoutCloud (Google Drive de l'utilisateur) n'est pas encore ouvert.
